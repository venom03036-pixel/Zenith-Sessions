## Implemented scope

The [reviewed design](PUBLIC-MEDIA-DESIGN.md) and [headshot ownership note](AUTOMATIC-HEADSHOTS-DESIGN.md) add one shared visible-page loader. It borrows the existing presenter/cache, deduplicates verified player IDs, retains at most 100 current metadata bindings and one pending manual request, and serializes actual requests. Imported/editable profile IDs are not authority. Manual refresh shares the same lane. Page/grant/player changes, hide, Lock/Panic and disposal fence late replies; shutdown joins actual work before disposing transport. Sample mode and default isolated test composition do not fetch automatically. Deferred images do not spin; retry uses explicit refresh or a later eligible page/cache expiry. A neutral silhouette replaces initials while a headshot is unavailable. No profile owns a browser, worker, refresh loop or capture source.

The optional gallery uses anonymous public v2 media discovery followed by explicit thumbnail-ID retrieval. It preserves discovery order using ID correlation, rejects foreign/duplicate IDs and unsafe image locations, and retains requested place separately from universe/root place. Empty, pending, unapproved, unavailable and unsupported video media remain explicit. No video URL is executed. Previous/Next wraps through at most ten items; only two decoded images remain cached. There is no automatic rotation timer in this increment.

One PNG implementation now has two fixed policies: original exact 150×150 avatars/icons, and 576×324 gallery images. CRC/chunk/order, animation/compressed-metadata rejection, bounded exact zlib output/Adler/consumption, Adam7 geometry and full detached frozen BGRA decoding apply to both. Gallery images cannot enter the square path. Two retained gallery pixel buffers total 1,492,992 bytes; encoded/in-flight/WIC/UI allocations are separate and this is not a process-memory measurement. Existing shared HTTP slots, cooldown and encoded-cache budgets remain authoritative.

The production game panel has previous/next controls, position, and media status, using Zenith theme resources. An optional icon failure no longer suppresses an independent gallery. Game-details operation ownership is published before observable callbacks, and terminal state is set before notifications so reentrant cancellation remains the last writer. No persisted schema, macro, input or capture contract changed.
