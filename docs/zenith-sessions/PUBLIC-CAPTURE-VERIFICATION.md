# Anonymous public response captures — R-research-10

The opt-in research tool `scripts/Capture-ZenithPublicFixtures.ps1 -Capture` uses seven fixed public HTTPS GET endpoints already used by Zenith. It disables cookies, redirects and default credentials, identifies itself as `ZenithSessions/0.50`, and limits each response to 64 KiB with a 15-second deadline. There is no retry and no 429 probe. This script requires PowerShell 7; it is not part of application startup or any test run.

On November 8, 2026, the final sanitizer captured six HTTP 200 responses (place mapping, game metadata, avatar headshot, game icon, public server list and Windows player version) and one HTTP 404 response for a nonexistent public user ID. No HTTP 429 occurred, so there is no claimed real 429 fixture. Existing synthetic rate-limit checks remain applicable. The first collection was repeated once after the sanitizer was finalized; the retained manifest describes the second collection only.

Only allowlisted fields are persisted. Names, IDs, job IDs, image URLs, cursor text and error messages become synthetic values; numerical counts, nulls and known response enums retain their shapes. Unknown fields, including player tokens, are discarded. Unexpected nonpublic markers retain nonempty synthetic values so they cannot become valid public server rows. Bodies and headers are never logged or saved before sanitization; failed captures retain an outcome and exception type only. These reduced samples cover the fields Zenith consumes, not every field Roblox may return.

`tests/Zenith.Sessions.Tests/fixtures/PublicCaptured.provenance.json` records exact source URLs, UTC times, HTTP statuses, byte limits, raw body sizes, sanitizer SHA-256 and sanitized fixture SHA-256. Parser tests check those hashes, replay the fixtures through the real HTTP-backed parsers using an in-memory handler, assert anonymous requests and exact request counts, and never access the network. The game test requires the synthetic place/universe correlation; the image tests require the synthetic subject IDs and address; the server test requires distinct synthetic join targets; the 404 remains Unknown and returns no profile.

Seven new fixture tests failed before captures existed (`artifacts/completion-d3/captures-before.trx`). After collecting them, 273 parser checks passed (`captures-after.trx`). The final seven fixture/provenance checks passed in `captures-accepted.trx`. A wider `captures-final.trx` run passed 275 checks but exposed one pre-existing Windows PowerShell 5.1 child-module-path failure and skipped the unavailable Luau binary check; those remain integration work, and this report does not count that run as green. `scripts/Test-ZenithPublicFixtureSanitizer.ps1` separately checks seven synthetic privacy/shape/size assertions without requests. These checks verify public parser compatibility with the recorded shapes; they establish no sign-in, current server availability or live launch qualification.
